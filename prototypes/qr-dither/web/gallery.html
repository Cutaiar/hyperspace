QR dither · gallery

Four-dimensional solids drawn in the data of a QR code — not overlaid on one. Every code here is solved by pyqart's contrast-ordered elimination, so the halo follows the drawing. Each file was rasterised by headless Chrome and decoded by zxing before it was written: all of them land on https://hyperspace.cutaiar.io plus an ignored #fragment.
Click any code to fill the screen, then scan it with your phone — that is the only test that counts.
