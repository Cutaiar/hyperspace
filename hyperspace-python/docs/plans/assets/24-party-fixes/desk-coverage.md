# Desk coverage — every preset's preset layer

Generated by `tools/desk_coverage.py` (plan 24 C3, decision 19); `tests/test_desk_coverage.py` fails when this file is stale. Do not edit it by hand: run `uv run python tools/desk_coverage.py`.

**The preset layer** is 38 controls: the device knobs D1–D8, the track knobs K1–K8, the track faders S1–S8, and every other control the default map gives a preset-layer row (G3·5, G3·6, G3·7, G3·8, G8·1, G8·2, G8·3, G8·4, G8·5, G8·6, G5·9, C, B16, B17), less any control the session holds on both layers. Each preset is loaded as the app loads it, from a scratch library holding only the corpus presets (tests/corpus/presets).

**● mapped**: a preset row is on the control and the preset can show its param. **· dark**: nothing is on it. **✕ dead**: a row is on it, but the preset cannot show the param — a pattern or bitmap knob with the faces off, points or lines opacity with that layer off, an effect's knob with the effects or that effect off, a look-back knob with the look-back off, a rotation rate or plane with rotation off (`learn.cannot_show`), or a param the registry lacks.

The owner's bar for the authoring pass: **at most 4 dark or dead** on the preset layer. This run reports it; no preset is remapped to meet it.
