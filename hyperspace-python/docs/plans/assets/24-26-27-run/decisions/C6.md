# C6 decisions — the palette fold

## Register-row drafts

**1xx. The palette is `fx.palette.*`, not `palette.*`.** Built: an effect file, so it appears on the FX page as a chip like the others and every param is learnable/routable. Other options: a core `palette.*` group (rejected by the prompt). To reverse: rename the file's ids and re-save presets (cheap while no preset uses it). Rough edge: ids differ from the working plan's. Judge it: U.1.

**1xx. It starts at mix 0 via a new `// @mix` header directive.** Built: switching the effect on changes nothing until the mix fader is raised. fx.py gained `@mix` (default 1; every other effect unchanged). Other options: leave mix at 1 and rely on identity-valued fold defaults (the triangle fold at width 360 is not an identity, so no). To reverse: delete the directive; then "on" would fold the picture. Rough edge: "on" with no visible change may look broken; the tip says "Mix 0 leaves the picture". Judge it: U.1.

**1xx. Anchor colours are 12 hue/sat/val params plus an `anchors` count (2-4).** Built: `a1..a4_hue/sat/val`, hue in degrees (wraps), grey ramp 0/0.333/0.667/1 as default. The first `anchors` colours are used dark to light, evenly spaced on brightness. Other options: RGB triples; shared saturation (8 params). To reverse: rename params (breaks saved palettes). Rough edge: 21 params; the strip packs hue/sat/val onto one row per anchor and shows one mode's rows at a time, so the other mode's rows are invisible on the strip until the mode flips. Judge it: U.2.

**1xx. `mode` is an int 0/1 param (fold / gradient map)**, because the @param form has no enum. Fader reads 0 or 1. Other options: add an enum form to fx.py. Judge it: U.1.

**1xx. `@order 95`, not 99.** Built: last in the stack but one hundred-scale room remains after it, so dragging a chip to the end rewrites one order. At 99 the "move to the end" case would rewrite two. Other options: 99. To reverse: edit the header.

**1xx. The fold's triangle is over the absolute hue wheel** (red at one end of the slice, cyan at the other), centred on `centre`. Value/saturation are linear rescales, so a raised `val_lo` lifts black to grey (as asked: a range). Judge it: U.1.

**1xx. The FX page is repacked, not resized (touches row 45's room, not its "three a row").** Built: the chip grid stays three a row; the gaps before the chips, after them, before the param rows and the 1 px under the strip header are gone, winning back the 13th chip's fifth row; strip rows pack `_lo/_hi` and `_hue/_sat/_val` params onto one row by name (`ui_fx.strip_rows`), and the palette shows only the open mode's rows (`ui_fx.HIDDEN_BY_MODE`, palette-specific: smaller than an @group tag). Hidden params stay declared and routable. Other options: four chips a row (names cut), an @group tag in fx.py. To reverse: restore the spacing, delete strip_rows. Rough edge: chips sit tighter to the status lines; a route on a hidden row cannot be seen on the strip. Judge it: U.2.

## Hand-check drafts

**U.1 Palette fold at the machine.** Headless: `tests/test_fx_palette.py` (byte-identical defaults, turned-up mix changes the frame, narrow slice is one hue, routed mix moves). Setup: FX page, open Palette, switch on (nothing changes), raise mix. *Pass:* hues pull onto a slice at centre; width 0 is one colour; centre sweeps the slice with no seam; mode 1 paints brightness through the grey ramp; a desk fader learned onto mix/centre rides it. *Fail:* a visible seam as centre sweeps (check the triangle in palette.glsl); picture changes at mix 0 (chain skip).

**U.2 Saved palette and the packed strip.** Headless: `test_a_saved_palette_is_an_fx_module_preset`, `test_the_palette_strip_fits_in_both_modes`. Setup: open Palette on the FX page; in fold mode (mode 0) the strip shows mode, centre, width, sat (lo+hi on one row), val (lo+hi); flip mode to 1 and it shows mode, anchors and one row per anchor (hue/sat/val). Set four anchors, save as an fx preset, load another, load it back. *Pass:* the FX page does not scroll in either mode (last anchor row and last fold row both reachable); only the open mode's rows show; the palette comes back from the fx preset list with its anchors. *Fail:* the page scrolls or a row is cut off (strip_rows / HIDDEN_BY_MODE in ui_fx.py), a mode's rows never appear (mode param not read), anchors missing after load (id typo).
