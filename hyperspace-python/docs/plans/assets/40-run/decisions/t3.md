# T3 decisions — save, browse, spawn (plan 40 P3, D2, D3, D9)

Branch `plan-40-t3` (base f8d2e73), commits 9915a63, 7cba583.

## 1. Register-row drafts

**50i — A spawn's open ports and rename map live on the group's entry for the session, never saved.**
- **Answer:** controller — 2026-10-27.
- **Built:** `Edit.spawn` puts the landing's `ports` and `renames` on the live `presets.groups` entry. `graphview.open_ports` reads them; the folded node draws one pin per port that is still open ("in · open (was scene)"), and a drag onto that pin lands on the member's port. The hover says "spawned as acid → acid.2 …". Undo and redo carry both keys, because the library's marks copy the groups. `preset.group_entry` writes neither key, so a save drops them, and after a reload the group has no open pins (`+` opens it).
- **Other options:** keep them in the panel's state, keyed by group id (undo would not follow them); save them in the preset (a new key, and plan 36 rules out hidden "where it was" data).
- **To reverse:** small. It is two keys and one reader.
- **Rough edge:** after a reload, a spawned group's **wire as saved** chip is gone. The file's `ports` are not re-read, because nothing re-reads the patch file.
- **Judge it:** 395 (Save and spawn), AK.5.

**50j — Wire as saved takes only free ports. It never takes over a fed one.**
- **Answer:** controller — 2026-10-27.
- **Built:** For an inlet, the preset must have the `was` node (the rig's outputs, channels, camera and clouds always count). For an outlet, nothing may be wired into the `was` port yet (`scene.geometry`, which takes many wires, excepted). Every other pin is refused in words: "output.all.image is taken", "no node tripcolour". The whole press is one undo step, and the chip hides once no pin is open. In party-trip the patch's out → output.all.image is refused while huecycle feeds that port.
- **Other options:** let the outlet take the port over, as T1's round-trip helper does (one press would silently cut the host's run).
- **To reverse:** one line in `Edit.wire_as_saved`.
- **Rough edge:** the most common host (one with a run into All outputs) refuses the outlet. The user drags it by hand or splices instead.
- **Judge it:** AK.5.

**50k — Save as patch refuses on a member a patch may not hold. A host macro left behind is only said.**
- **Answer:** controller — 2026-10-27.
- **Built:** `Edit.save_patch` asks `patches.select` first. Any refusal, for example a hand-edited group holding `scene`, is shown on the head, and nothing is written. A host macro's subscriber on a member (`patches.HOST_MACRO_WORDS`) does not block the save; it is shown after "saved X as a patch".
- **Other options:** block on every word `lift` returns, as the build plan's wording reads literally.
- **To reverse:** one line.
- **Rough edge:** none known.
- **Judge it:** 395, AK.6.

**50l — Saving a group as a patch sets its `patch` in one undo step. The file write is not undone.**
- **Answer:** controller — 2026-10-27.
- **Built:** the step is labelled "save <group> as patch <name>". Only the group's `patch` field changes, and the preset's dirty dot lights. ⌘Z gives the old provenance back, and the file stays. Updating with the same slug pushes no step.
- **Other options:** no undo step (the dirty dot would light with nothing to undo).
- **To reverse:** delete one `_step`.
- **Rough edge:** none.
- **Judge it:** 395.

**50m — A `kept_by_host` entry is the patch's row after renames, plus its control in `words`.**
- **Answer:** controller — 2026-10-27.
- **Built:** the shape is `{"source": "cc:0:48", "target": "fx.acid.2.speed", "op": "abs", "feedback": "ring", "words": "K1"}`. The words use the desk's glyph when the table is the APC40's. `graphview.kept_words` prefers `words`, so the node says "K1 kept by the preset" rather than "CC 48 ch1". The entry is saved in the preset's `groups` (T2's `group_entry` already writes it).
- **Other options:** also store the conflict kind (not needed by anything yet).
- **To reverse:** small.
- **Rough edge:** a kept row is information only. Nothing offers to "take it now" later; the user re-binds by hand.
- **Judge it:** 397, 401.

**50n — While the sheet is up, `Learn.hold`: no source completes a learn, and the armed learn waits.**
- **Answer:** controller — 2026-10-27.
- **Built:** while held, `Learn.accepts` says no, which covers the hands, the desk, a pad and OSC (each completer asks it). `ui_routing.modal` keeps the flag in step every frame, and `settle_sheet` releases it. Replace / Keep relies instead on `learning` being cleared before the referee answers. That cannot cover a sheet raised while a learn is armed, so the dispatch's fallback (a flag) was taken.
- **Other options:** cancel the armed learn when the sheet opens (the user's learn would be lost).
- **To reverse:** small.
- **Rough edge:** none.
- **Judge it:** 397.

**50o — The sheet's wants are T4's words over the landing's own rows.**
- **Answer:** controller — 2026-10-27.
- **Built:** `ui_routing.sheet_wants` builds a table-like object from the landing's routes, desk rows and modifiers, and runs `devices.wants` against the panel's registry. The lines read "apc40 (lost): K1" and "leap (not in this rig): right hand y". With no registry, every device reads "not in this rig". The "waits for hand: …" by-scheme fallback was not needed.
- **Other options:** word `Landing.wants` by scheme head.
- **To reverse:** small.
- **Rough edge:** the sheet lists wants only when there are conflicts. A conflict-free spawn into a rig that lacks a device says nothing at the spawn; the group node's status line says it next frame.
- **Judge it:** 397, 398.

**50p — If the preset moved while the sheet was up, Spawn is refused.**
- **Answer:** controller — 2026-10-27.
- **Built:** `Edit._spawn_refusal` checks that the landing's render names, modifier ids and voices are still free. If not, the head says "the preset changed while the sheet was up: spawn X again", nothing lands, and no undo step is pushed. This also stops a second Spawn of the same landing.
- **Other options:** recompute the landing at the press and map the answers across.
- **To reverse:** small.
- **Rough edge:** practically unreachable through the UI, because the modal is modal.
- **Judge it:** none (headless only).

**50q — The browser chip sits first on the GRAPH head, after plan 38's hold chips.**
- **Answer:** controller — 2026-10-27.
- **Built:** the spec says "beside **new** and the starters", but the GRAPH head has no **new** chip; new lives on the PRESET strip and the starters are in the canvas menu. **patches** comes first so it is found.
- **Other options:** after the tint chip, or on the PRESET strip.
- **To reverse:** one line.
- **Rough edge:** the head line grows by one chip on a narrow panel.
- **Judge it:** 395.

**50r — `update patch` sits beside `save as patch…`.**
- **Answer:** controller — 2026-10-27.
- **Built:** for a group with a `patch`, both chips show on the side pane and both items in the group's menu. Update opens the form prefilled with the patch file's own name and note; save as… prefills the group's name.
- **Other options:** show update only.
- **To reverse:** small.
- **Rough edge:** none.
- **Judge it:** 395.

**50s — A dragged patch's drop target is the canvas's picture cables only.**
- **Answer:** controller — 2026-10-27.
- **Built:** while a browser line is dragged, the picture cable nearest the pointer lights (`graphview.cable_near` over the render cables, last frame's pin positions). It lights only when the patch has exactly one inlet and one outlet of the cable's type and the cable is the section's (not the rig's bus). Otherwise the hover says why ("x has 2 picture inlets and 1 outlet: a splice needs one of each"). Letting go on a lit cable splices; letting go anywhere else does nothing. A folded group's stub is never a target (T2's minor).
- **Other options:** an imgui drop target. The node editor's links are not imgui items, so they cannot take a payload.
- **To reverse:** n/a.
- **Rough edge:** the drag gesture has not been driven headless. It is covered by hand check 396.
- **Judge it:** 396.

## 3. As built

**What was built**
- `graphview` (the edit layer):
  - `Edit.spawn(landing, choices, splice=None)`: one undo step, the doors in load order; see 50i and 50m.
  - `Edit.splice`, `Edit.wire_as_saved` (50j), `Edit.save_patch` (50k, 50l), `Edit._spawn_rows`, `Edit._spawn_refusal` (50p).
  - Module-level: `open_ports` and `_open_pins` (drawn on the folded node through `attach_groups`), `patch_pins`, `splice_refusal`, `splice_target`, `patch_words` (the browser's boundary words), `_splice` (`_onto`'s twin for an inlet and outlet pair).
  - `kept_words` prefers the entry's `words`.
- `preset.Presets.parts()`: spec, table, the performance snapshot (a held program's own params left out), layout.
- `learn.Learn.hold` / `held`, checked in `accepts` (50n).
- `ui_routing`: the sheet in `modal`, ahead of Replace / Keep, at `SHEET_W`. Helpers: `sheet`, `choose`, `keep_all` (also **take all**), `settle_sheet`, `conflict_words`, `sheet_wants` (50o), `sheet_title`. `st["sheet"]` beside `st["modal"]`.
- `ui_graph`:
  - The browser: the **patches** chip on the head (50q), `patch_list`, `_patch_rows` as a drag source, **spawn ▸** in the canvas's picker, `_drop_target` / `_patch_drop` (50s), with the drop cable lit in `_cable`.
  - `spawn` (`Host.of` with the held program's names, then the sheet or straight on) and `land_spawn`.
  - The side pane's `_group_chips`: wire as saved, save as patch…, update patch, and the form. Save / update are also on the group menu.
  - The fresh ids on the group's hover.
- `ui_presets`: `patches_fold` after `more`. `_list_row` serves PATCHES with no pick, and `_rename` takes the group.

**Where it differs from the spec, and why**
- **Spawn ids.** "acid-wash into party-trip lands acid.2, wobble.2, delay.2" is not what the rule gives. party-trip has none of those effects, so the first spawn keeps `acid`, `wobble`, `delay` and `mod.1`, and the second spawn takes `.2` / `mod.2`. The tests assert the rule as it is.
- **Splice cable.** The splice is tested on `scene → plasma.image`, because party-trip has no `warp`. The run reads `scene → acid → wobble → delay → plasma`; `graph.run_of(spec, "scene", "delay.image") == ("acid", "wobble")`, since a delay is not part of an effects run.
- **"the hand row".** acid-wash's hand reaches the patch through `mod.1`'s input. That is no route and no conflict (T1's 474x).
- **Wire as saved** uses `render_wire`'s rules through one re-read (`_land`), not `render_add`, which adds nodes, not cables.
- **"one inlet and one outlet"** counts the file's picture, geometry and mask ports. A value port is a row, and a row never blocks a splice.

**What no person has verified**
- The sheet's look at `SHEET_W`.
- The drag from the popup onto a cable: the highlight colour, and whether the popup stays up during the drag.
- Open pins on the folded node.
- The side pane's form.
- The PRESETS fold's layout.

**Known rough edges**
- The open pins and **wire as saved** are session-only (50i).
- The outlet refusal in a typical host (50j).
- `patch_list` stats each patch file every frame, but only while the popup or menu is open or a drag is live.

- The dispatch asks for the hold mechanism "the Replace / Keep prompt uses today" (clearing `learning`). I built its fallback instead, a `Learn.hold` flag, because clearing `learning` would cancel the user's armed learn (50n).
