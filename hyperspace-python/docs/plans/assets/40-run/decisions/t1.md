## 1. Register-row drafts (number inside 471–495)

**471x. The patch's modifier lane in the spec's example.**
**Answer** controller — 2026-10-27: `mod:1`. The spec's P1 example routes `"source": "mod:0"`
from `mod.1`; a modifier's lane is `mod:<n>` for `mod.<n>` (`modifiers.Modifier.address`;
`id_of("mod:0")` is None), so `mod:0` is no lane and the route would have dropped dormant.
**Built** tests/fixtures/patches/acid-wash.json is the spec's example with `mod:1`; every
other key is as P1 prints it (`acid`, `wobble` exist as factory effects).
**Other options** keep `mod:0` and treat the lane as dormant. **To reverse** one character in
the fixture. **Rough edge** the spec text still says `mod:0` until T6 writes "as built".
**Judge it** AK.1 (Spawn ▸ acid wash: the right hand moves wobble's amount through the smooth).

**472x. A patch's envelopes are 6 and up, in the file too.**
**Answer** controller — 2026-10-27. P1 says a patch's ids are "the lowest, as if alone" and that
lane envelopes 1–5 are refused by identity. An envelope lifted as `env.1` would read as a lane
envelope; so `lift` renames a patch's envelopes from `env.6`, and `check` refuses an `envs`
entry 1–5 in words. **Built** an envelope in a patch file is `env.6`, `env.7`…; spawned it takes
the host bank's next id (never below 6). **Other options** `env.1`… in the file, mapped at spawn.
**To reverse** `FIRST_ENV` in patches.py and one test. **Rough edge** none seen.
**Judge it** a headless test (`test_lift_renames_to_the_lowest_ids_and_rebases_the_layout`).

**473x. A macro "in use" is a label, a subscriber or a row onto it — not its value.**
**Answer** controller — 2026-10-27 (the dispatch asked to pick one rule). `Host.of` counts a
macro used when the table holds a label or a subscriber for it, or any route / desk row
targets it. Its value alone does not count: the eight knobs always have one (every factory
preset holds `macro.1..8 = 1.0`). **Built** a patch's `macro.2` keeps its number in a host that
does not use it; else the lowest free of the eight (renamed in the map); none free → the note
"macro.2: no free macro — its subscribers not spawned", and its value, subscribers and every
row onto it stay out; the rest spawns. **Other options** value off default; subscriber only.
**To reverse** `Host.of`'s `used` set. **Rough edge** a host macro moved by hand but with no
subscriber is taken. **Judge it** AK.2.

**474x. Which schemes are one-owner sources (the "performer source" conflict).**
**Answer** controller — 2026-10-27. Rules applied, scheme by scheme:
- `cc:` / `note:` / `pitch:` (any `@role`): a **desk** conflict when a host preset-layer row
  overlaps the patch's (`Binding.overlaps` — same device qualifier, kind, number, channel or
  any-channel). Whatever the host row's target.
- `hand:` and `axis:` (any `@role`): a **source** conflict when a host performer route reads
  the same source string onto a different param (Learn's "one axis, one param", plan 18
  fork 7; a pad stick is learned the same way). Exact string match (no router to resolve a
  label to a lane).
- every other scheme (`lane:`, `hands:`, `key:`, `pad:`, `hat:`, `ext:`, `seq:`, an OSC role, a
  host `lfo:` / `env:` / `mod:` lane): **no** source conflict — such a source drives any number
  of params (party-noita's `lane:0` drives two).
- any route of the patch's (rig row or host port) onto a param the host's `Bindings.owner`
  already has: a **target** conflict (the third kind; a rig row onto a renamed member id can
  only hit a dormant host route left on that id).
A row gets at most one conflict (source before target).
**For the owner to rule on — read through a modifier is no conflict.** The source rule looks
at *routes* only. A one-owner source a patch reads through a **modifier input** is never a
conflict, even where the host's own row on that axis already owns a param: acid-wash's
`smooth` reads `hand:right.y`; spawned into party-noita, where `hand:right.y` drives
`fx.warp.amount` and two more, the sheet lists no hand conflict (only K1). The spec's D3
example names exactly "`hand:right.y` already owns a param". Built this way because a
modifier only *reads* the lane (many readers are fine; the table's one-owner rule is per
target), but if the owner means "one axis, one meaning", modifier inputs on `ONE_OWNER`
schemes should be checked too (a few lines in `spawn`).
**Dormant rows wake.** The lowest free instance may be one the host's dormant rows still name
(a removed `acid.2`'s params): spawning `acid` as `acid.2` brings those routes and desk rows
back to life, unsaid and no conflict — the same as `_new_instance` on the canvas today.
**Other options** every continuous scheme one-owner; hands only. **To reverse** `ONE_OWNER` in patches.py. **Rough edge** a
spawn of a noita cut back into party-noita lists four hand conflicts (its own hands already
drive the originals) — correct by the rule, noisy in the sheet. **Judge it** spec check AK 397
(K1 in party-acid) and AK.3.

**475x. `lift` returns `(doc, refused)`.**
**Answer** controller — 2026-10-27. The build plan writes `lift(...) → dict` and "return the
refusals; the caller says them and lifts the rest". **Built** a tuple: the file's dict
(`schema`, `name` and `note` empty) and the refusals in words. Its third argument is the
registry's performance snapshot (a dict), not the registry — pure. **Other options** a
dataclass; refusals inside the doc. **To reverse** the call sites (T3). **Rough edge** none.
**Judge it** headless.

**476x. Hidden factory patches live in `hidden.json` under `"patches"`.**
**Answer** controller — 2026-10-27. `Library.hide` only took the presets' group; the dispatch
asked that `list` / `hide` work for patches "with no new code" — not possible without
widening `hide`. **Built** `HIDEABLE = (presets, patches)`: × hides a factory patch by stem in
`hidden.json`'s `"patches"` list, written only when non-empty (a home that hides none writes
exactly the old file); `rename` takes a user patch the same way, less step 5 (no show names
a patch). **Other options** a second file. **To reverse** small: `HIDEABLE` and the key.
**Rough edge** an older build reading a `hidden.json` with `"patches"` ignores the key (it reads
only `presets`) — harmless. **Judge it** AK.4.

**477x. A port's ids, and what `was` holds.**
**Answer** controller — 2026-10-27. Inlets `in`, `in.2`…, outlets `out`, `out.2`… in wire order;
an inlet's `was` is its source's name (`scene`, `channel.a`, a pin as written), an outlet's the
port it went into (`tripcolour.image`, `output.all.image`). One port per crossing wire (a
member feeding two host ports is two outlets). The value crossings derived at `read` are
`{"id": "value.<k>", "type": "value", ...}` — `graph.VALUE`, the port type plan 30 named.
**To reverse** cheap until T3 draws them. **Judge it** spec check AK 394.

**478x. A hands entry's `laid` is not carried.** `lift` drops `laid` from an extra hands
entry: how the frame's one layer is laid is the host's, and a second `laid` makes the host
section unreadable ("laid twice"). **Judge it** headless only.

**479x. A copy goes only with its original.** `lift` refuses a copy whose `of` is not picked
("copy draws acid again: take acid with it; left out"); `check` refuses the same in a file.

## 3. As built

- Review fixes (2026-10-27): a wire with an end outside the patch is refused by `check` ("…
  crosses the edge: a port says it") and never emitted by `spawn` (D2); a voice that does not
  spawn (full bank, or ids past `modbank.MAX_ID`) leaves its lane nowhere — a modifier input on
  it is emptied and said, depth/base subscribers on it dropped; `Host.of` without banks starts

  only members' values (D5 without `check`); `Host.params` removed — nothing needs the registry
  ids (a route onto a param the host lacks lands dormant and is no conflict).

  `lift` → `(doc, refused)`, `Host` (+ `Host.of(spec, table, banks, held)`), `spawn` →
