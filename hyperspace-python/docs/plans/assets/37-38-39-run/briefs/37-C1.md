   `Preview`; say which and why): a small texture per node name, the long
   side `THUMB_PX = 192`, the node's aspect, made at the frame's end in
   `Renderer._for_the_panel` for every node id the page **wanted this
   frame** (`want(ids)`): ask the node's picture through `graph.picture`
   (an `IMAGE`-output node), blit it down (one blit per node; mipmaps or a
   downsample pass — pick the cheaper that reads well and say). Kept by
   node name; **dropped when not wanted for a second**. Shared with the
   control window's context the way `Preview`'s texture is. A node that
   made nothing this frame (not reached, off, no frame yet) keeps its last
   thumbnail **dimmed, then black after a second**: a flag/age the page
   reads, not a copy. A node not on screen, hidden (preset only) or
   collapsed-off-canvas costs nothing — the page never wants it. Count the
   blits this frame (`PreviewTextures.count` or similar) for the SYSTEM
   line.
   - What a non-picture node shows (spec P1): a geometry node (`shape`,
     `cloud`, `hands`) its scene's picture faint (the first `scene` its
     geometry reaches; if none, nothing); a hands node its layer if one is
     wired; an output the window's picture (output 1 through the existing
     `Preview` tap; other outputs: their presenter's picture if it is
     reachable without a new readback, else nothing — say which); the
     modulation side (LFOs, envelopes, modifiers, devices, macros, the
     analyzer) stays text. Keep this mapping one table.

     again into a frame target. Say in the report what each kind costs
