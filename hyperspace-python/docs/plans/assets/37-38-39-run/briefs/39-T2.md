## Build (exactly T2 of the build plan)
1. **The promotion** in `graph.py`: `_wired_error` accepts a `MASK` maker
   into an `IMAGE` port. The consumer sees a picture — white
   (premultiplied, opaque) where the mask passes, black elsewhere — at the
   consumer's size, fitted by cover as an own-sized node is
   (`Node.picture_of_mask` or the shape that fits the code; the paint is
   `masks.PROMOTE_FS` into a `_frame_target`). The reverse (a picture into
   a mask port) is refused with words that name `matte`: "`x` makes a
   picture, `y.mask` takes a mask — put a `matte` between". No node of
   plan 36 or earlier changes: `scene.cover → lookback.cover` is unchanged.
2. **`matte[.n]`**: `MatteAt` + reader + every table line; `MatteNode`,
   INPUTS `{"image": IMAGE}`, OUTPUT MASK, own size its input's; one
   channel 8-bit out. Params (group `matte`, the preset's, all
   modulatable): `matte.from` choice **luma | alpha | chroma** (chroma =
   distance from `matte.hue` at `matte.sat`), `matte.key` 0–1 (where a
   pixel starts to pass), `matte.soft` 0–0.5 (the edge's width; 0 hard),
   `matte.invert`, `matte.feather` 0–32 px (a separable blur, two chained
   passes inside the node, only when > 0). Unwired: makes nothing and says
   so. Defaults so that a wired matte on a plain picture does something
   sensible (luma, key 0.5, soft 0, no feather) — a new node, so "today's
   picture" is "not there"; say the defaults in the decisions file.
