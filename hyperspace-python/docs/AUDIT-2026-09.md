# Audit — open findings

Defects that are true of the code today, each checked against the code it
names. A finding that is fixed is deleted from this file (git keeps it).
Sizes: **S** ≤ ½ day, **M** ≈ 1–2 days. Ids are kept, because code
comments and other documents cite them.

## Small defects

Each is one line to fix.

- **`macro` reads changed right after `lfo-breathe` loads.** `preset.py`
  sets `macro.1` to 0.0 against the registry's default of 1.0, so the
  `macro` group is dirty at load; no page draws that group's dot
  (`ui_presets.OVERVIEW_GROUPS` leaves `macro` out).
- **`placement.read` accepts `monitor = true` or `1.9` silently.**
  `int(monitor)` reads them as 1 with no note; only a value `int()` refuses
  gets the note.
- **No test holds the learn half of the fader pick-up.** A message an armed
  desk learn takes also makes the control's pickup rows pick up again
  (`MidiIO._passed_over`, called from the learn branch of `_handle`); only
  the disabled-row half has a test.
- **Code comments cite documents and row numbers that are gone.** Comments
  across `hyperspace/`, `tests/` and `tools/` still name the deleted
  blueprint and plan files (`__init__.py`, `app.py`, `bridge.py`,
  `config.py`, `dream.py`, `library.py`, `lookback.py`, `midi.py`,
  `params.py`, `preset.py`, `tools/hands_probe.py`, `tools/hands_tape.py`,
  three tests), answered decision-register rows 1–33 and closed audit ids
  ("audit A10"). They are provenance, not instructions; `config.py`'s
  docstring also says `[midi] enabled = false` drops hand Learn, which is
  false. The party show files' notes name the deleted `12-presets.md`.
- **Stale docstrings and comments:**
  - `ghost.Ghost.readout`: says the readout layer is drawn "only while the
    guide is on"; it is drawn while the guide or the tethers are on.
  - `ghost.py` module docstring and the `ghost.on` tip: the hands are drawn
    "after every effect"; that is only the default (through off).
  - `render.py`, the comment before the pipeline loop in
    `Renderer._draw_frame`: the history is captured "after the first
    composite"; it is captured once, after every pipeline.
  - `app._open_presenters`: states "121 fps against 60–81" as fact; it is
    unconfirmed (hand check 107).
  - `outputs.py` module docstring: names scene, hands and dim, not through.
  - `ui.Panel._page_presets`: "the eight preset buttons"; the bank is 24.
  - `hands/core.py` module docstring: right-click → Learn "writes a
    `position` route"; most hand Learns now write a push
    (`learn.Learn._row`).
  - `midi.py` module docstring: a learn "on an invariant control … is
    refused"; an invariant control now does its own job through an armed
    learn.
  - `render.Renderer._tile` docstring and a message in
    `tests/test_render.py`: "instance grid"; the layout may be HEX or RING.
  - `library/dream/wake.json` note: "Echo mix, fade, hue and dream mix",
    the old labels (now Echo brightness, Echo fade time, Dream hue, Dream
    brightness).
