# Audit — September 2026

What plan 10's reading found: places where the code and the documents
disagree, concepts spelled twice, boundary leaks, dead code, and tests
that no longer say what they mean. Recorded against `main` **ef299ef**
(2026-09-27; line numbers as of plan 10's docstring commit 488c445) by eight readers, one per component, each checking every
claim against the code. **Nothing here was fixed in plan 10** except
docstrings and comments (listed at the end as done); everything else is
filed for plan 11.

Sizes: **S** ≤ ½ day, **M** ≈ 1–2 days, **L** ≈ 3–4 days. Grouped by
component, ordered within each group by the cost of leaving it. The
documents this audit produced — [`ARCHITECTURE.md`](ARCHITECTURE.md),
[`DECISIONS.md`](DECISIONS.md), the refreshed
[`ENGINEERING.md`](ENGINEERING.md) — describe the code as it is, including
the behaviour listed here; fixing an item means updating the line that
describes it.
