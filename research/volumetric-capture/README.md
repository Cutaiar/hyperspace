# Volumetric crowd capture

The living plan for the OV9281 capture rig (stereo first, then N cameras, a
5×5 m floor) is now a shared doc, edited there rather than here:

**[Volumetric Crowd Capture](https://claude.ai/artifact/PUbGkasHMBaRmZ5ZtdBTXx)**

It covers the decisions so far, the roadmap and gates, how the software
changes from stereo to N cameras, calibration sensitivity, the 5×5 m
geometry, the tracker, interfaces, buy lists and open questions.
